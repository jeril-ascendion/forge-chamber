## Project Identity

**App name:** Forge Chamber
**Tagline:** Where engineers get tested
**Type:** Multi-platform — Desktop (Electron) + Web + Mobile (Capacitor)
**Distribution:**
  - Desktop: Single installer (.exe Windows, .dmg macOS)
  - Web: Static build deployed to S3 + CloudFront
  - Mobile: iOS (.ipa) and Android (.apk) via Capacitor
**Backend:** Python FastAPI + LiveKit Agents
  - Desktop: Bundled as PyInstaller exe, runs on localhost:8765
  - Web + Mobile: Deployed to server, called via HTTPS
**Primary user:** Software engineers at Ascendion Digital Services
**Architecture:** Option C — one React codebase, three platform wrappers

---

## Platform Architecture

```
React App (ONE codebase — frontend/)
      │
      ├── desktop/   → Electron shell  → Windows .exe / macOS .dmg
      ├── (none)     → Browser         → Web app via S3 + CloudFront
      └── mobile/    → Capacitor shell → iOS .ipa + Android .apk

Backend (backend/)
      ├── Desktop:     PyInstaller exe bundled in installer, localhost:8765
      └── Web+Mobile:  FastAPI on EC2/ECS, called via HTTPS API
```

The key rule: components never call Electron or Capacitor directly.
Everything platform-specific goes through usePlatform() hook.

## usePlatform Hook — THE KEY ABSTRACTION

Every component that needs OS capabilities MUST use this hook.
Never call window.electronAPI or Capacitor plugins directly from components.

```typescript
// frontend/src/hooks/usePlatform.ts
import { Capacitor } from '@capacitor/core'

export function usePlatform() {
  const isElectron = !!(window as any).electronAPI
  const isNative   = Capacitor.isNativePlatform()  // iOS or Android
  const isWeb      = !isElectron && !isNative

  async function pickFiles(): Promise<string[]> {
    if (isElectron) return window.electronAPI.pickFiles()
    if (isNative) {
      const { FilePicker } = await import('@capawesome/capacitor-file-picker')
      const result = await FilePicker.pickFiles({ types: ['application/pdf'] })
      return result.files.map(f => f.path ?? f.name)
    }
    return webFilePicker()
  }

  async function requestMic(): Promise<MediaStream> {
    if (isNative) {
      const { Microphone } = await import('@mozartec/capacitor-microphone')
      await Microphone.requestPermissions()
    }
    return navigator.mediaDevices.getUserMedia({ audio: true })
  }

  async function saveApiKeys(keys: Record<string, string>): Promise<void> {
    if (isElectron) return window.electronAPI.saveApiKeys(keys)
    if (isNative) {
      const { Preferences } = await import('@capacitor/preferences')
      for (const [k, v] of Object.entries(keys))
        await Preferences.set({ key: k, value: v })
      return
    }
    Object.entries(keys).forEach(([k, v]) => localStorage.setItem(k, v))
  }

  async function hasApiKeys(): Promise<boolean> {
    if (isElectron) return window.electronAPI.hasApiKeys()
    if (isNative) {
      const { Preferences } = await import('@capacitor/preferences')
      const { value } = await Preferences.get({ key: 'ANTHROPIC_API_KEY' })
      return !!value
    }
    return !!localStorage.getItem('ANTHROPIC_API_KEY')
  }

  return { isElectron, isNative, isWeb, pickFiles, requestMic, saveApiKeys, hasApiKeys }
}
```

## API Client — Auto-selects Backend URL

```typescript
// frontend/src/lib/api.ts

const BASE_URL = (window as any).electronAPI
  ? 'http://localhost:8765'
  : (import.meta.env.VITE_API_URL ?? 'https://api.forgechamber.ascendion.com')

export async function apiFetch<T>(path: string, opts?: RequestInit): Promise<T> {
  const res = await fetch(`${BASE_URL}${path}`, {
    headers: { 'Content-Type': 'application/json' },
    ...opts,
  })
  if (!res.ok) throw new Error(`API ${res.status}: ${path}`)
  return res.json()
}
```

## What NOT To Do

- Do NOT call window.electronAPI directly from components — use usePlatform()
- Do NOT call Capacitor plugins directly from components — use usePlatform()
- Do NOT hardcode http://localhost:8765 anywhere except api.ts
- Do NOT use position:fixed in CSS — breaks Capacitor WebView on iOS
- Do NOT use localStorage for API keys on mobile — use @capacitor/preferences
- Do NOT use PostgreSQL for desktop — SQLite only, zero setup for users
- Do NOT use any TypeScript types — fully type everything
- Do NOT put platform logic inside components — only in usePlatform()
- Do NOT use heavy chart libraries — SkillRadar is pure SVG
